# DUNYA — شبکه اجتماعی (نسخه اولیه قابل اجرا)

این پروژه یک MVP واقعی و قابل توسعه است: ثبت‌نام/ورود، تأیید ایمیل یا شماره با OTP، پروفایل پایه، انتشار پست متنی/عکس/ویدئو، لایک و کامنت. فایل‌های رسانه‌ای در Cloudinary و اطلاعات در MongoDB Atlas ذخیره می‌شوند.

## پیش‌نیازها
- حساب MongoDB Atlas و یک دیتابیس
- حساب Cloudinary
- برای ارسال کد ایمیل: SMTP معتبر
- برای ارسال کد پیامک: حساب Twilio و شماره مجاز (ارسال پیامک بین‌المللی ممکن است هزینه و محدودیت کشوری داشته باشد)
- حساب Render برای میزبانی

## اجرای محلی
1. Node.js نسخه 20 یا جدیدتر نصب کنید.
2. فایل `.env.example` را به `.env` تغییر نام دهید و مقادیر را تکمیل کنید.
3. در ترمینال اجرا کنید:
   ```bash
   npm install
   npm start
   ```
4. آدرس `http://localhost:10000` را باز کنید.

برای آزمایش بدون سرویس ارسال کد، فقط در محیط محلی `DEV_RETURN_OTP=true` بگذارید. این گزینه را در محیط عمومی/تولیدی فعال نکنید.

## انتشار روی Render
1. فایل ZIP را استخراج و پروژه را در یک مخزن خصوصی GitHub قرار دهید.
2. در Render گزینه New → Blueprint را انتخاب و مخزن را وصل کنید؛ `render.yaml` تنظیمات سرویس را می‌خواند.
3. در Environment سرویس، `MONGODB_URI`، سه مقدار Cloudinary و تنظیمات SMTP/Twilio را وارد کنید.
4. پس از Deploy، آدرس `/api/health` را باز کنید. باید `ok: true` و `database: connected` ببینید.
5. مقدار `CLIENT_URL` را برابر آدرس سرویس Render قرار دهید یا در صورت استفاده از دامنه اختصاصی به‌روزرسانی کنید.

## متغیرهای لازم
- `MONGODB_URI`
- `JWT_SECRET` (یک مقدار طولانی و تصادفی؛ Render می‌تواند آن را بسازد)
- `CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`
- برای ایمیل: `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `MAIL_FROM`
- برای پیامک: `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_PHONE_NUMBER`

## نکات مهم قبل از عرضه عمومی
- این نسخه پایه است، نه محصول نهایی در مقیاس فیسبوک.
- پرداخت واقعی، کیف پول، فروشگاه، تبلیغات پولی، چت زنده، استوری، گزارش تخلف و پنل مدیریت هنوز پیاده‌سازی نشده‌اند و باید در فازهای بعدی با کنترل‌های امنیتی و تست اضافه شوند.
- برای پرداخت، باید ارائه‌دهنده‌ای انتخاب شود که کشور محل کسب‌وکار و کشورهای مشتریان را پشتیبانی کند. پول کاربران را تا قبل از پیاده‌سازی سیستم حسابداری/تطبیق و الزامات قانونی در کیف پول واقعی نگه ندارید.
- برای محیط تولید، محدودیت نوع فایل، اسکن بدافزار، حذف امن رسانه، سیاست حریم خصوصی، شرایط استفاده، پشتیبان‌گیری و مانیتورینگ را تکمیل کنید.
- هیچ‌گاه کلیدهای Cloudinary، JWT، SMTP یا Twilio را در کد فرانت‌اند یا مخزن عمومی قرار ندهید.
